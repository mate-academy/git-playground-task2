# Notes

## Commands

- `notes add <text>` adds a note
- `notes list` lists all notes
- `notes search <term>` finds notes containing the term (case-sensitive)
- `notes delete <id>` deletes a note

## Changelog

- Fixed `matches()` in `lib/store.js`: search now matches notes that contain the term instead of requiring an exact match.
